## 🧠 About Me

I'm a **Creative Technologist & Software Engineer from India** who enjoys turning ideas into things people can actually **use, see and experience**.

My work sits somewhere between:

```text
        SOFTWARE
           │
           ├── Full-Stack Development
           ├── Interactive Experiences
           ├── Game Development
           │
           ▼
      CREATIVE TECH
           │
           ├── Motion & Visuals
           ├── Video & Editing
           ├── 3D / Blender
           └── UI / UX
```

I enjoy projects where engineering isn't just about making something work — it's also about making the experience **interesting, intuitive and visually engaging**.

### ⚡ Currently interested in

* 🚀 Full-stack web applications
* 🎮 Game & interactive experience development
* 🎬 Video editing & motion design
* 🧊 3D, Blender & visual experimentation
* 🎨 UI/UX & creative interfaces
* 🧠 Exploring new technologies and creative workflows

> **I don't want to choose between code and creativity — I like building where both meet.**
